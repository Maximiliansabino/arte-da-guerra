PARA QUEM MANTÉM O GITHUB
1. Guarde alterações locais: faça commit ou stash em sua cópia.
2. Execute git fetch origin e confira novos commits do seu amigo.
3. Crie uma branch de integração a partir da main atualizada.
4. O patch arte-da-guerra-1.0.1.patch, ao lado da pasta do jogo no ZIP,
   foi gerado contra o commit base acima. Dentro do repositório execute:
   git apply --check /caminho/arte-da-guerra-1.0.1.patch
5. Se passar, aplique com git apply /caminho/arte-da-guerra-1.0.1.patch.
   Se houver conflito, faça a conciliação arquivo a arquivo. Não force
   nem substitua a pasta inteira sobre trabalho novo.
6. Rode npm test; teste entrada, senhas, prontidão e uma partida completa.
7. Revise o diff e só então faça seu commit, PR e publicação habituais.
